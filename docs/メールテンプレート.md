# メールテンプレート（仮）

最終更新: 2026-08-14 / ステータス: **仮案。スプレッドシート作成時に確認・修正する**

`{{ }}` は差し込み変数。**★は毎回の手入力が必須**（自動計算せず、入力しないと送信できない設計にする）。
実際の運用ではこの内容をスプレッドシートの「テンプレ」タブに格納し、そちらで編集する。
このファイルは常に最新の内容に同期する。

> **注意**: 本リポジトリは公開設定のため、電話番号など外部に出したくない値は `{{ }}` のままとし、
> 実際の値はスプレッドシートの「設定」タブに保持する。

---

## 変数一覧

| 変数 | 取得元 | 備考 |

| `{{発送先TEL}}` | 設定タブ | |
| `{{営業所コード}}` `{{営業所名}}` | 設定タブ | 現在: 160652 / 松原柴垣営業所 |

## T3. Square 請求書のメッセージ欄

Square 管理画面 → 請求書 で使用。件名は
`サービスご利用における決済情報のご登録とご署名に関するお願い`。
既存の請求書と設定を揃える（詳細設定は要確認）。

```
お世話になっております。
ササゲパス運営事務局です。

サービスご利用にあたり、お手数ですが下記2点のご対応をお願いいたします。

1. カード情報の保存について

メール画面の「カードで支払う」ボタンからお支払い手続きをお願いします。
お手数ですが「Google Pay」ではなく「クレジットカード」を選択し、
「カード情報をササゲパスに保存する」に必ずチェックを入れたうえで
決済を完了してください。

　※以降は、毎月のご利用実績に応じて発生したご請求額が、
　　保存いただいたカードから自動的に引き落としされます。

2. 契約書へのご署名について

メール画面下部の「契約書を表示」より契約書をご確認いただき、
内容に問題がなければ電子署名をお願いいたします。

ご不明点がございましたら、本メールへのご返信にてお気軽にご連絡ください。
今後ともどうぞよろしくお願いいたします。

ササゲパス運営事務局
```

```
ありがとうございます。

商品のご発送をお願いいたします。発送先は前回のご案内のとおりです。
ご発送後、本メールへのご返信にて、
送り状のお問い合わせ番号またはお控えの写真をお送りいただけますと幸いです。

　受付開始日　：{{受付開始日}}
　納期の目安　：{{納期予定}}

どうぞよろしくお願い申し上げます。
```

## T5. リマインド：お手続きが未完了の場合

案内メール送付から一定日数、署名・入金が確認できない場合。

件名: `【ササゲパス】お手続きのご確認`

```
{{会社名}}
{{担当者名}} 様

お世話になっております。ササゲパス運営事務局です。

先日お送りしたご請求書について、
決済情報のご登録と契約書へのご署名がまだ確認できておりません。

お手続きが完了しませんと作業を開始できないため、
恐れ入りますがご確認をお願いいたします。
すでにお手続き済みの場合や、ご不明な点、
ご都合が変わった場合などございましたら、本メールへのご返信にてお知らせください。

どうぞよろしくお願い申し上げます。
```

## T6. リマインド：追跡番号の連絡がない場合

手続き完了から一定日数、追跡番号の連絡も荷物の到着もない場合。

件名: `【ササゲパス】ご発送状況のご確認`

```
{{会社名}}
{{担当者名}} 様

お世話になっております。ササゲパス運営事務局です。

ご発送のご準備はいかがでしょうか。
すでにご発送済みの場合は、本メールへのご返信にて、
送り状のお問い合わせ番号またはお控えの写真をお送りください。

まだの場合もお急ぎいただく必要はございませんので、
ご都合のよいタイミングでご発送ください。

どうぞよろしくお願い申し上げます。
```
