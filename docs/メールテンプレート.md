# メールテンプレート（仮）

最終更新: 2026-08-14 / ステータス: **仮案。スプレッドシート作成時に確認・修正する**

`{{ }}` は差し込み変数。**★は毎回の手入力が必須**（自動計算せず、入力しないと送信できない設計にする）。
実際の運用ではこの内容をスプレッドシートの「テンプレ」タブに格納し、そちらで編集する。
このファイルは常に最新の内容に同期する。

> **注意**: 本リポジトリは公開設定のため、電話番号など外部に出したくない値は `{{ }}` のままとし、
> 実際の値はスプレッドシートの「設定」タブに保持する。

## T3. Square 請求書のメッセージ欄

Square 管理画面 → 請求書 で使用。件名は
`サービスご利用における決済情報のご登録とご署名に関するお願い`。
既存の請求書と設定を揃える（詳細設定は要確認）。

```
お世話になっております。
ササゲパス運営事務局です。

サービスご利用にあたり、お手数ですが下記2点のご対応をお願いいたします。

1. カード情報の保存について

メール画面の「カードで支払う」ボタンからお支払い手続きをお願いします。
お手数ですが「Google Pay」ではなく「クレジットカード」を選択し、
「カード情報をササゲパスに保存する」に必ずチェックを入れたうえで
決済を完了してください。

　※以降は、毎月のご利用実績に応じて発生したご請求額が、
　　保存いただいたカードから自動的に引き落としされます。

2. 契約書へのご署名について

メール画面下部の「契約書を表示」より契約書をご確認いただき、
内容に問題がなければ電子署名をお願いいたします。

ご不明点がございましたら、本メールへのご返信にてお気軽にご連絡ください。
今後ともどうぞよろしくお願いいたします。

ササゲパス運営事務局
```

## T2B. 依頼確定（2回目以降）

件名: `【ササゲパス】ご依頼を承りました（発送先・スケジュールのご案内）`

**カード登録と契約書署名は初回だけ。** 契約済みのお客様には、
T2 から「ご発送前のお手続き（お支払い方法のご登録）」と
「初回のみ納期を長くいただく」旨の注記を外し、月々のご請求の説明を添えたものを送る。
登録手数料220円の請求書も作らない。

送信すると案件のステータスは **発送待ち** になる（支払い・署名待ちを飛ばす）。

T2 との違いだけを示す。

```
（冒頭）
このたびはご依頼をいただき、誠にありがとうございます。
　→ いつもご利用いただき、誠にありがとうございます。

（ご依頼内容の注記）
※初回のみ、ストア情報登録のため、通常より大幅に納期をいただいております。
　→ 削除

（ご発送前のお手続き（お支払い方法のご登録）のブロック）
　→ 下記に差し替え

━━━━━━━━━━━━━━━━━━━━
■ ご請求について
━━━━━━━━━━━━━━━━━━━━
今回のご利用ぶんは月末締めでまとめ、
ご登録いただいているカードより自動でお支払いいただきます。
お客様にてお手続きいただく必要はございません。
```

「対応を選ぶ」では、そのお客様の登録状況を見て**ふさわしいほうを先頭に出す**。
合わないほうを選ぶと赤字で注意を出すが、選ぶこと自体は妨げない。

## T9. 返送開始のお知らせ

件名: `【ササゲパス】商品の返送を開始いたしました`

**この送信が月々のご請求の対象になる。** 点数と追跡番号は「対応を選ぶ」で手入力し、
送った内容はそのまま返送履歴へ残る。案件のステータスは `返送済` になる。

末尾の「次回のご依頼について」は、**次のご依頼をいただくための入り口**。
返送の連絡はいちばん読まれるので、ここに置いている。

伺うのは2点だけにした。**多く聞くほど返信が遅れる。**

| 伺うこと | なぜそれだけでよいか |
|---|---|
| ご依頼予定数 | ずれても2〜3回のご依頼にわたって調整できる。正確さは要らない |
| ご発送予定日 | 受付開始日と納期は、ご連絡をいただいた時点でこちらから出し直す |
| （変更があるときだけ）ご依頼内容 | 変更がなければ書かなくてよい。**依頼内容と単価の変更はこちらで手で行う** |

すでにテンプレを作ったあとのスプレッドシートにも、`boardMigrateShipBackNextOrder_` が
締めの一文の前へ差し込む。**手で書き換えた本文は壊さない**（見出しが無いときだけ足す）。

```
{{会社名}}
{{担当者名}} 様

お預かりしておりました商品の返送を開始いたしましたので、ご連絡いたします。

ご登録いただいているカードより自動でお支払いいただきますので、
お客様にてお手続きいただく必要はございません。

お手元に届きましたら、内容をご確認いただけますと幸いです。

　・ご依頼予定数　：　　　点
```
