# スプレッドシート設計

最終更新: 2026-08-15

対象スプレッドシート: 見積もりフォームの回答が蓄積されている既存シート
（ID はスクリプトのプロパティ `BOARD_SPREADSHEET_ID` ではなく、バインド先として自動解決）

**このファイルはシート構造を変更するたびに必ず更新する。**

---

## タブ一覧

| タブ | 役割 | 作成元 |
|---|---|---|
| 案件ボード | 進行中の案件一覧。ここだけ見れば回る | 新規 |
| 顧客 | 顧客マスタ。請求・返送に必要な情報を保持 | 新規 |
| メール履歴 | AI返信案と送信済み文面の記録（②で使用） | 新規 |
| テンプレ | メール文面 T1〜T7 | 新規 |
| ナレッジ | 回答方針メモ・返信実例（②で使用） | 新規 |
| 設定 | 発送先・通知先などの値 | 新規 |
| ログ | 実行履歴 | 新規 |
| `Config` | **既存。見積もりフォームの設定JSON。変更禁止** | 既存（非表示） |
| `Responses` | **既存。フォーム回答の生データ。変更禁止・読み取りのみ** | 既存（非表示） |

既存2タブはフォームが読み書きしているため一切変更しない。
案件・顧客の行は `Responses` を**読み取って**生成する。

## 案件ボード

1行＝1案件。A〜G列が常時表示（見やすさ優先）、H列以降は詳細。

| 列 | 項目 | 種別 |
|---|---|---|
| A | 案件ID | 自動（`A001`〜） |
| B | ステータス | プルダウン＋色分け |
| C | お客様 | 自動（顧客タブから） |
| D | 点数 | 手入力 |
| E | 受付開始日 | **★手入力必須** |
| F | 納期予定 | **★手入力必須** |
| G | 次にやること | **数式で自動表示** |
| H | 顧客ID | 自動 |
| I | 依頼内容 | 自動（フォーム回答） |
| J | 単価 | 自動（フォーム回答） |
| K | 請求書URL | 手入力 |
| L | 請求書送付日 | 自動（メール作成時） |
| M | 署名・支払確認日 | 手入力 |
| N | 追跡番号 | 自動抽出／手入力 |
| O | 案内メール作成日 | 自動（下書き作成時） |
| P | 最終連絡日 | 自動 |
| Q | メモ | 手入力 |
| R | 元回答行 | 自動（`Responses` の行番号。重複取込の防止） |

### ステータスと色

| ステータス | 色 | 意味 |
|---|---|---|
| 問合せ | アンバー | フォーム回答直後。未返信 |
| 返信済 | アンバー | こちらから返信済み。相手待ち |
| 依頼確定 | パープル | 受注。案内メール未送付 |
| 手続き待ち | ブルー | 案内メール送付済。署名・支払い待ち |
| 発送待ち | ティール | 手続き完了。商品の到着待ち |
| 作業中 | グレー | 商品到着済 |
| 返送済 | グレー | 完了 |
| 見送り | グレー | 失注・中止 |

### G列「次にやること」の判定

ステータスと日付から自動で文章を生成する。放置案件は赤字。

| 条件 | 表示 |
|---|---|
| 問合せ | 返信案を確認して返信 |
| 返信済 | お客様の返信待ち |
| 依頼確定 かつ 日付未入力 | 日付を入れて案内メール |
| 依頼確定 かつ 日付入力済 | 案内メールを送る |
| 手続き待ち | 署名・支払い待ち（N日経過） |
| 発送待ち | 追跡番号の連絡待ち |
| 作業中 | 作業 〜M/D |

## 顧客

1行＝1顧客。**キーはメールアドレス**。同じアドレスからの再問い合わせは既存行を更新する。
Square の請求書作成と返送に必要な情報を保持し、一覧で確認・修正できる。

| 列 | 項目 | 種別 |
|---|---|---|
| A | 顧客ID | 自動（`C001`〜） |
| B | 会社名・屋号 | フォームから自動／修正可 |
| C | 担当者名 | フォームから自動／修正可 |
| D | メールアドレス | フォームから自動（**キー**） |
| E | 電話番号 | フォームから自動／修正可 |
| F | 返送先 郵便番号 | 手入力 |
| G | 返送先 住所 | 手入力 |
| H | 返送先 宛名 | 手入力 |
| I | 依頼内容 | フォームから自動／修正可 |
| J | 月間予定数 | フォームから自動 |
| K | 単価 | フォームから自動／修正可 |
| L | 初回問い合わせ日 | 自動 |
| M | 最終更新日 | 自動 |
| N | メモ | 手入力 |

B〜E は Square の請求書作成にそのまま使える項目として揃えている。
F〜H の返送先はフォームで取得していないため、案件が確定した段階で手入力する。

## メニュー操作

スプレッドシート上部の「ササゲパス」メニュー。

| 項目 | 動作 |
|---|---|
| 初期セットアップ | 上記タブを作成（何度実行しても既存データは壊さない） |
| フォーム回答を取り込む | `Responses` の未取込行から顧客・案件を作成 |
| 案件を開く | 選択行の詳細をサイドパネルで開く |

## サイドパネル

案件ボードで行を選び「案件を開く」で表示。

- 受付開始日・納期予定・点数・請求書URL を入力して保存
- ［案内メールの下書きを作る］ … **受付開始日と納期予定が両方入るまで押せない**
- ［このお客様のメールを開く］ … Gmail の検索結果を開く
